Snail Meet
🐌 peer-to-peer, no server, no video

Meetings that take their time.

A voice-and-text meeting room that connects two browsers directly — no account, no backend, no camera. Just an invite code and a reply code, exchanged once, and you're talking.

🔌

No server required

Runs as static files. Host it on GitHub Pages, Netlify, or open it straight from disk.

🔒

Direct connection

Messages travel browser-to-browser over WebRTC once the handshake is done — nothing passes through a middleman.

🎙️

Voice, when you want it

Mic-to-mic audio over the same connection. No camera, ever — just talk.
